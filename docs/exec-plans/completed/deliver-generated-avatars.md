# Deliver stable generated profile avatars

## Purpose / Big Picture

Give every account a deterministic geometric SVG avatar generated by the API
from its immutable user UUID. Display it in the account menu and profile; name
or email changes must not change the image. Preserve the exact approved palette,
grid shapes, FNV-1a hash and finalizer from the disposable avatar handoff.

## Context And Orientation

`apps/api/src/modules/avatars` owns rendering and response caching. API modules
are registered in `apps/api/src/app.module.ts`. `SessionView.userId` and
`Profile.id` already supply UUIDs; web components must not import API internals.
The same-origin `/api/` ingress works in development and production.

## Validation And Acceptance

Same seed/size yields identical SVG and ETag; dimensions are 16–512 (default64).
Invalid seeds and sizes return400. Matching conditional requests return304.
Responses carry SVG MIME, immutable caching and safe document headers. User
redirects accept UUIDs and reveal no account state. Pin sample output digests,
exercise shape/palette distribution, and parse XML in the browser. Profile/menu
images load with JavaScript enabled and disabled and persist across renames.

## Concrete Steps

Run `bun run verify`, then `bun run test:browser` in the isolated acceptance
copy. Inspect phone and desktop screenshots. Run `bun run check:docs` after
recording evidence. Do not reset or migrate the user's local database.

## Idempotence And Recovery

No persistence, migration, package or external service is introduced. Builds
and checks are repeatable; cached avatars depend only on their input. Future
algorithm changes require a versioned URL to avoid stale immutable responses.

## Interfaces And Dependencies

NestJS, Express, class-validator and class-transformer already exist. Size is
a transformed integer query parameter. ETags include generator version, seed
and size; the SVG never embeds the seed. Uploaded-photo redirects are deferred.

## Surprises & Discoveries

The original handoff uses root routes; the application routes `/api/` to Nest
and everything else to Next, so namespacing avoids a second proxy contract.

## Artifacts And Notes

Generator source is the durable copy of the exact approved algorithm. Tests
pin outputs for `user-1`, `user-2` and a fixed UUID. No real account data is used.
